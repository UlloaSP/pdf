# HTML a PDF

Convierte texto de un archivo HTML local a PDF. Omite scripts y estilos; no reproduce CSS, imágenes, JavaScript ni páginas web por URL.

La salida se crea en el directorio de trabajo del motor. Las entradas originales se conservan.

Las pruebas generan documentos locales y comprueban la salida. Las dependencias externas y el hardware se comprueban mediante dobles; su validación real queda pendiente cuando no están instalados.

El archivo debe estar codificado en UTF-8. La fuente PDF estándar cubre texto occidental; no se garantiza representación de otros alfabetos. Una futura conversión visual necesita un motor de navegador.
