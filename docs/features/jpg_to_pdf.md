# Imagen a PDF

Convierte imágenes en páginas PDF en el orden seleccionado.

Una página por imagen, tamaño derivado de DPI. Aplica orientación EXIF y fondo blanco a transparencias. Usa el primer fotograma de imágenes animadas.

Validación: unittest con PDF de tres páginas generado por ReportLab; comprueba resultado y rechazo de entradas inválidas.
