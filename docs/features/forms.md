# Rellenar formularios

Rellena campos de texto AcroForm existentes mediante JSON.

Rellena campos de texto existentes. No crea campos nuevos, no detecta formularios escaneados, no admite XFA, firmas ni casillas. Los nombres disponibles se muestran si un nombre no existe.

Validación: unittest con PDF de tres páginas generado por ReportLab; comprueba resultado y rechazo de entradas inválidas.
