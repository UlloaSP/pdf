# Generador de memes

Añade texto superior e inferior blanco con contorno negro y ajuste automático.

Texto Latin-1 blanco con contorno negro, salto de línea y reducción de fuente para ocupar como máximo el tercio superior/inferior. Rechaza texto que no cabe a 8 px. No plantillas descargadas, generación IA ni animaciones. El contenido central permanece sin overlays.

Entrada máxima de 40 megapíxeles y 20.000 px por lado. Aplica EXIF y procesa el primer fotograma. Salida PNG con nombre único y sin alterar originales. Tests con imágenes generadas verifican píxeles, orientación, límites y errores.
