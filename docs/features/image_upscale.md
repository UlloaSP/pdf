# Ampliar imagen

Ampliación integrada 2× o 4× con interpolación Lanczos de Pillow. No es superresolución por IA ni recupera detalle perdido. PNG de salida con transparencia y orientación EXIF aplicada; metadata descartada. Solo imágenes estáticas; rechaza archivos animados y TIFF multipágina para no descartar fotogramas silenciosamente.

Hasta 100 archivos, máximo 40 millones de píxeles de salida por imagen. Nombres exclusivos y originales intactos. Tests comprueban dimensiones, transparencia, EXIF, límites y rechazo de animaciones.
